# LIONXSEC

## Publisher Desktop

برنامهٔ فارسی آماده‌سازی محتوا و زمان‌بندی انتشار در تلگرام در پوشهٔ [`publisher`](publisher) قرار دارد.

- [راهنمای نصب و اجرای Windows Server 2016](publisher/WINDOWS-SERVER-2016_FA.md)
- [دریافت نسخهٔ ۱.۳.۳ با فیلتر محتوایی قابل خاموش‌کردن](downloads/LIONXSEC-Publisher-Desktop-v1.3.3.zip)
- [راهنمای OpenAI، پاک‌کردن نتیجه و رفع مشکل TXT](publisher/OPENAI-AND-RESCAN_FA.md)
- [راهنمای کامل برنامه](publisher/README_FA.md)
- [آزمون‌ها و محدودیت‌های بررسی‌شده](publisher/VALIDATION.md)

ZIP را دریافت و کامل استخراج کنید؛ سپس `START-LIONXSEC.cmd` را اجرا کنید. در ZIP کامل مخزن، برنامه داخل پوشهٔ `publisher` است. Python نسخهٔ ۶۴ بیتی 3.10 تا 3.13 و .NET Framework 4.6.2 یا جدیدتر لازم است. راه‌انداز در صورت نبودن WebView2، نصب‌کنندهٔ رسمی x64 را دانلود می‌کند، امضای مایکروسافت را بررسی و Runtime را نصب می‌کند. در سرور ۲۰۱۶ باید **Desktop Experience** و نشست دسکتاپ فعال داشته باشید.

نسخهٔ ۱.۳ دکمهٔ پاک‌کردن نتیجه، بررسی مجدد فایل‌های ارسال‌نشده و تنظیمات OpenAI دارد. در تنظیمات استودیو، OpenAI را انتخاب و کلید API را داخل برنامه وارد کنید؛ سپس «بررسی محتوا» را بزنید. عنوان، کپشن، دستهٔ محتوا و تاریخ درج‌شده در منبع تشخیص داده می‌شوند. پس از بازبینی و تنظیم حساب تلگرام و کانال، «شروع زمان‌بندی» انتشار را فعال می‌کند.

این برنامه از WebView2 در ویندوز و Qt WebEngine در لینوکس استفاده می‌کند. ۹۲ آزمون خودکار، آزمون مرورگر، پنجرهٔ واقعی لینوکس و پردازش رسانه موفق‌اند؛ اجرای واقعی روی Windows Server 2016، OpenAI با کلید واقعی و ارتباط با حساب زندهٔ تلگرام هنوز در محیط توسعه آزموده نشده‌اند.
