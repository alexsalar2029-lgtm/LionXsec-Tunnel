# آپلود خودکار یوتیوب
با Python 3.11 یا جدیدتر، در پوشهٔ پروژه یک محیط مجازی بسازید، فعال کنید و دستورهای زیر را اجرا کنید.

    python -m pip install -r requirements.txt
    python -m unittest -v

در Google Cloud برای برنامه YouTube Data API v3 را فعال کنید، صفحهٔ رضایت OAuth را تنظیم کنید و فایل OAuth client از نوع Desktop app را دریافت کنید. برای عرضهٔ عمومی، انتشار و در صورت نیاز تأیید OAuth توسط گوگل را تکمیل کنید. مجوز آفلاین در حالت External / Testing معمولاً پس از هفت روز منقضی می‌شود.

روی رایانه‌ای که مرورگر دارد یک بار کانال مقصد را انتخاب و دسترسی آپلود را تأیید کنید.

    python uploader.py connect client_secret.json
    python uploader.py watch queue

فایل کامل را ابتدا با پسوند موقت در queue/inbox بنویسید، سپس نام نهایی مانند film.mp4 را بدهید. برنامه تا وقتی اجرا می‌شود هر ده ثانیه پوشه را بررسی می‌کند. عنوان ویدیو نام فایل است و وضعیت انتشار خصوصی است. پس از موفقیت فایل و شناسهٔ ویدیو در queue/done نگهداری می‌شوند. اگر عملیات با خطا قطع شد، فایل در processing می‌ماند. پیش از برگرداندن آن به inbox ابتدا کانال را بررسی کنید تا ویدیو دوباره ارسال نشود.

مجوز در پوشهٔ شخصی کاربر در .youtube-auto/authorization.json ذخیره می‌شود. دسترسی به این مسیر را به کاربر اجراکننده محدود کنید. برای VPS بدون مرورگر، اتصال اولیه را در دستگاه خود انجام دهید و فایل مجوز را از مسیر امن به همان مسیر حساب اجراکننده در VPS انتقال دهید. برای چند کانال، برای هر کانال پوشهٔ مجوز و صف مستقل تعیین کنید، مثلاً python uploader.py --state channel1 connect client_secret.json و سپس python uploader.py --state channel1 watch queue1. در صورت لغو مجوز، اتصال مجدد لازم می‌شود.
