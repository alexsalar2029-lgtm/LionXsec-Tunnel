# OpenAI و بررسی دوبارهٔ محتوا — نسخهٔ ۱.۳

## راه‌اندازی

1. برنامه را با `START-LIONXSEC.cmd` باز کن. در «تنظیمات استودیو» به «هوش مصنوعی محتوا» برو و «تولید و دسته‌بندی خودکار محتوا» را فعال کن.
2. سرویس **OpenAI API** و مدل `gpt-4.1-mini` را انتخاب کن. مدل دیگری باید از تصویر و خروجی ساختاریافته در Responses API پشتیبانی کند.
3. کلید API را فقط در فیلد داخل برنامه وارد کن و «بررسی اتصال هوش مصنوعی» را بزن. این کار تنظیمات و کلید را ذخیره و دسترسی به مدل را بررسی می‌کند. موفقیت این بررسی به‌تنهایی کافی‌بودن اعتبار برای تحلیل را تضمین نمی‌کند؛ نتیجهٔ اولین بررسی محتوا را هم ببین.
4. در کتابخانه پوشهٔ فایل‌ها را انتخاب و «بررسی محتوا» را بزن. روی پست کلیک کن و عنوان، کپشن، نوع محتوا و تاریخ منبع را بازبینی کن.
5. حساب تلگرام، کانال و ساعت‌های انتشار را تنظیم کن و «شروع زمان‌بندی» را بزن. برنامه باید باز و اینترنت متصل بماند.

در OpenAI، متن و تصویر یا سه فریم ویدیو از طریق HTTPS به سرویس فرستاده می‌شوند؛ صوت و تمام ثانیه‌های ویدیو تحلیل نمی‌شوند. درخواست‌ها `store: false` دارند؛ شرایط نگهداری داده تابع حساب و سیاست OpenAI است. حساب API هزینهٔ جداگانه دارد و اشتراک ChatGPT اعتبار API محسوب نمی‌شود. هر بررسی دستی می‌تواند درخواست API تازه بسازد؛ پایش خودکار برای فایل بدون تغییر درخواست تکراری نمی‌فرستد.

کلید در ویندوز با DPAPI برای همان کاربر محافظت می‌شود. فیلد بعد از ذخیره خالی می‌شود و فقط وضعیت ذخیره‌شدن نشان داده می‌شود. برای تعویض، کلید جدید وارد کن؛ برای حذف، «حذف کلید ذخیره‌شده» را بزن. کلید را در چت، فایل محتوا یا گیت‌هاب نگذار.

## پاک‌کردن و بررسی دوباره

- **بررسی محتوا:** فایل‌های ارسال‌نشده را از نو می‌خواند؛ نوع فایل، عنوان، کپشن، دسته و تاریخ منبع دوباره تعیین می‌شوند. ویرایش دستی قبلی جایگزین می‌شود. فایل‌های کنارگذاشته‌شده در بررسی عمومی نادیده گرفته می‌شوند.
- **بررسی دوباره در پنجرهٔ پست:** فقط همان فایل را دوباره می‌خواند. برای پست‌های مسدودشده و کنارگذاشته‌شده هم فعال است.
- **پاک‌کردن نتیجه:** بعد از تأیید، نتیجه و نسخه‌های خروجی ساخته‌شدهٔ ارسال‌نشده را پاک می‌کند. سپس باید بررسی محتوا را بزنی. این دکمه در کتابخانه برای همه و در پنجرهٔ پست برای یک فایل وجود دارد. مورد کنارگذاشته‌شده هم پس از پاک‌کردن، دوباره قابل بررسی می‌شود.

این عملیات انتشار را متوقف می‌کنند. اصل فایل‌ها، سوابق ارسال، ارسال جاری و موارد «نیاز به بررسی ارسال» حفظ می‌شوند. برای ادامه پس از بازبینی، «شروع زمان‌بندی» را بزن. فایل ارسال‌شدهٔ بدون تغییر دوباره منتشر نمی‌شود؛ تغییر محتوای همان فایل پس از ارسال، محتوای جدید محسوب می‌شود.

نوع فیزیکی فایل از پسوند و امضای خود فایل تشخیص داده می‌شود. دستهٔ محتوا مثل «آموزشی»، «خبری» یا «رویداد» پیشنهاد AI است. تاریخ منبع فقط وقتی در محتوا وجود داشته باشد نمایش داده می‌شود؛ در TXT و PDF، تاریخ پیشنهادی باید عیناً در متن خوانده‌شده باشد. تاریخ و ساعت انتشار همیشه از ساعت سیستم و منطقهٔ زمانی تنظیم‌شده ساخته می‌شوند.

## رفع «محتوا قابل انتشار نیست» برای TXT

پست را باز کن و علت دقیق را بخوان. در نسخهٔ قبلی، نتیجهٔ مسدودشده امکان بررسی مجدد نداشت و وجود دو ایمیل حتی در متن توضیحی می‌توانست باعث تشخیص نادرست شود. هر دو رفتار اصلاح شده‌اند.

اگر فایل عادی است، مستقیم «بررسی دوباره» را بزن؛ پاک‌کردن نتیجه اجباری نیست. اگر اطلاعات ورود، رمز یا فهرست دادهٔ حساس در فایل وجود دارد، ابتدا فایل اصلی را اصلاح و ذخیره کن، سپس دوباره بررسی کن. تشخیص AI هم ممکن است اشتباه کند؛ بررسی دوباره درخواست تازه می‌فرستد. باقی‌ماندن محتوای حساس پس از پاک‌کردن نتیجه به معنی مجازشدن انتشار آن نیست.

| پیام | اقدام |
| --- | --- |
| کلید OpenAI وارد نشده / نامعتبر است | کلید معتبر را در تنظیمات وارد و اتصال را بررسی کن. |
| اعتبار API کافی نیست | اعتبار و محدودیت هزینهٔ پروژه را در حساب OpenAI بررسی کن؛ سپس دوباره محتوا را بررسی کن. |
| محدودیت درخواست | کمی بعد دوباره بررسی کن. |
| مدل در دسترس نیست / درخواست پذیرفته نشد | نام مدل، مجوز پروژه و پشتیبانی از Responses API و خروجی ساختاریافته را بررسی کن. |
| اتصال به OpenAI برقرار نشد | دسترسی همین سیستم به `api.openai.com` را بررسی کن و دوباره تلاش کن. |
| نتیجه پاک شده / تنظیمات هنگام بررسی تغییر کرد | تحلیل تازه با «بررسی دوباره» انجام بده. |
| متن خوانده نمی‌شود | فایل TXT را در ویرایشگر با UTF-8 ذخیره و دوباره بررسی کن. |

خطای کلید، شبکه یا اعتبار API به وضعیت «نیاز به بررسی» می‌رود؛ این خطاها نشانهٔ غیرقابل انتشار بودن متن نیستند. نسخهٔ ۱.۳ با پاسخ‌های شبیه‌سازی‌شدهٔ OpenAI آزمایش شده است؛ اتصال واقعی و کیفیت تشخیص مدل به حساب، شبکه و محتوای شما بستگی دارد.
