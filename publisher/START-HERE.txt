LIONXSEC Publisher Studio 1.3.0 — OpenAI + Clear / Recheck

۱. ZIP را کامل در پوشه‌ای جدید و قابل نوشتن Extract کنید.
۲. Windows 10/11 یا Windows Server 2016 به بعد با Desktop Experience لازم است.
۳. Python 3.10 تا 3.13 نسخهٔ ۶۴ بیتی را نصب کنید و Add Python to PATH را فعال کنید.
۴. .NET Framework 4.6.2 یا جدیدتر باید فعال باشد.
   راه‌انداز، WebView2 Runtime را در صورت نبودن، پس از بررسی امضای مایکروسافت نصب می‌کند.
   برای نصب دستی WebView2 Runtime نسخهٔ x64:
   https://developer.microsoft.com/microsoft-edge/webview2/#download
۵. START-LIONXSEC.cmd را اجرا کنید و تا پایان نصب اولیه صبر کنید.
۶. در صورت مشکل گرافیکی، START-LIONXSEC-SOFTWARE.cmd را اجرا کنید.

برای عنوان، کپشن، نوع محتوا و تاریخ منبع با OpenAI:
۷. تنظیمات استودیو ← هوش مصنوعی محتوا: تولید خودکار را فعال و OpenAI API را انتخاب کنید.
۸. مدل gpt-4.1-mini و کلید API خودتان را وارد و «بررسی اتصال هوش مصنوعی» را بزنید.
   کلید داخل همین برنامه ذخیره می‌شود؛ آن را در چت یا گیت‌هاب نفرستید. API هزینهٔ جداگانه دارد.
۹. پوشه را انتخاب و «بررسی محتوا» را بزنید. هر بار، فایل‌های ارسال‌نشده دوباره خوانده می‌شوند.
   برای حذف نتیجهٔ قبلی، «پاک‌کردن نتیجه» را بزنید و دوباره بررسی کنید.
   فایل TXT که قبلاً مسدود شده هم از پنجرهٔ پست با «بررسی دوباره» قابل بررسی است.
۱۰. پیش‌نمایش را ببینید؛ حساب تلگرام، کانال و ساعت‌ها را تنظیم و «شروع زمان‌بندی» را بزنید.

پاک‌کردن نتیجه، اصل فایل‌ها و سابقهٔ ارسال را حفظ می‌کند؛ عنوان و ویرایش‌های قبلیِ ارسال‌نشده حذف می‌شوند.
تاریخ منبع فقط از خود محتوا استخراج می‌شود. تاریخ انتشار از ساعت و منطقهٔ زمانی برنامه می‌آید.
