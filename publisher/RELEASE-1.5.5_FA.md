# 1.5.5 — اصلاح اعمال زمان‌بندی

تعداد روزانه و بازهٔ ساعت با «ذخیره» یا «شروع زمان‌بندی» خودکار اعمال می‌شوند؛ دیگر زدن «ساخت ساعت‌ها» ضروری نیست. شروع ابتدا فرم را ذخیره می‌کند و صف قبلی را با ساعت‌های جدید می‌چیند. ورودی نامعتبر مانع شروع می‌شود.

برای ۲۰ پست از شش عصر تا نیمه‌شب: تعداد 20، شروع 18:00، پایان 00:00. برای شش صبح، شروع 06:00. پایان نیمه‌شب، آخرین نوبت 23:59 همان روز را ایجاد می‌کند. اگر پس از شروع بازه فعال کنید، ساعت‌های گذشته جبران نمی‌شوند؛ انتشار از نوبت بعدی ادامه دارد. تعداد به موجودی پست‌های آماده در صف وابسته است.

اعتبارسنجی: ۱۳۵ آزمون Python موفق؛ آزمون واقعی رابط Qt و پل JavaScript با زدن مستقیم شروع بدون ساخت ساعت‌ها یا ذخیره، تأیید ۲۰ ساعت از 18:00 تا 23:59، حفظ تنظیمات پس از بازخوانی پایگاه داده و ذخیرهٔ بازه از 06:00. ارسال زنده تلگرام و Windows آزمایش نشده‌اند.
